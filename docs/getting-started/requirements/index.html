System requirements

What you need to run the launcher and to build mods.

To play with mods#

RequirementDetails
Operating systemWindows 10 or Windows 11, 64-bit
GameStormworks: Build and Rescue (Steam), 64-bit executable stormworks64.exe
Game versionThe version listed under Supported game versions. The loader fails closed on any other build.
WebView2The launcher window needs the Microsoft Edge WebView2 runtime. It is present on current Windows 10 and 11.
RightsStart launcher and game with the same rights (both normal, or both as administrator).
Only 64-bit

The game and the dedicated server have been 64-bit only since v1.15.25. There is no 32-bit support.

To build mods#

RequirementDetails
Windows64-bit
CMake3.20 or newer
CompilerVisual Studio 2022 with the Desktop development with C++ workload (MSVC)
LanguageC++17

See Development environment setup.
