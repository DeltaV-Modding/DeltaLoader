Mod loader for Stormworks: Build and Rescue

DeltaLoader

Install and run native mods for Stormworks: Build and Rescue. A launcher, an injector and a public C++ SDK, built on a verified mapping of the game.

What it does

  • Install mods from a catalog

    The launcher lists mods from the DeltaV mods site, verifies the SHA-256 of every download and installs it.

  • One switch per mod

    Turn mods on or off in the launcher and start the game with exactly the mods that are switched on.

  • Fails closed

    Native mods only load when the game executable matches the mapping (SHA-256 and byte signatures). After a game update they stay out until the mapping is updated.

  • Native C++ SDK

    Hooks, live objects, tiles, weather, rendering, audio and more through the headers of the public SDK.

  • Files without touching the game

    Mod folders (Data, Meshes, Graphics) appear in the game through an overlay or a virtual file system; originals are restored.

  • Open about its limits

    Single-player only. No anti-cheat bypass, no multiplayer. The documentation says what is proven and what is not.

Quick installation

  1. Download the launcher from the mods site and run it.
  2. Let it find your Stormworks folder (Settings → Game).
  3. Install a mod in Browse, switch it on in Installed.
  4. Press Play.
